About RouteWise

RouteWise is a lightweight road trip planner developed as a Semester III Web Technology mini project at Shah & Anchor Kutchhi Engineering College. It helps users estimate travel distance, travel time, fuel cost, weather conditions and nearby facilities using public APIs.

Academic Project

Developed using HTML5, CSS3 and JavaScript following the SAKEC Semester III Web Technology syllabus.

Our Mission

Provide a simple and responsive platform for planning road trips with useful travel information.

Core Stack

HTML5, CSS3, JavaScript, Fetch API, LocalStorage, OpenStreetMap, Open-Meteo API and OpenRouteService API.
