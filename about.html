About RouteWise

RouteWise is an intelligent, lightweight road trip planning platform built as a Web Technology course project for Shah & Anchor Kutchhi Engineering College (SAKEC), Computer Engineering Department (Semester III).

Academic Project

Strictly compliant with the SAKEC Semester III Web Technology curriculum using HTML5, CSS3, and vanilla JavaScript.

Our Mission

To deliver real-time route calculations, fuel cost estimates, destination weather, and nearby amenities on a clean, accessible interface.

Core Stack

Pure client-side DOM manipulation, Fetch API, LocalStorage persistence, OpenRouteService, Open-Meteo, and Overpass API integrations.
